## 🧠 概要

このプロジェクトは、福本伸行先生の漫画『賭博破戒録カイジ』に登場するチンチロリンのゲームを  
**Pythonで再現した非公式ファン作品**です。

- プレイヤー vs 大槻（CPU）との3回戦
- 各ラウンドで賭け金（ペリカ）を掛け、勝敗で増減
- 出目は原作準拠（ピンゾロ / ゾロ目 / シゴロ / ヒフミ / 目あり / 出目なし）
- 最終的な所持ペリカに応じて運命が分かれる……ッ！

---

## 💻 使用技術

- Python 3.12
- 標準ライブラリのみ使用（`random`）
